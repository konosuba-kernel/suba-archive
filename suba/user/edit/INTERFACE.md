# 编辑与构建界面

K7 的生产编辑器入口为 `user::edit::app::main`，复用已验收的 `buffer`、`motion`、UTF-8 和
字体核心。桌面启动 `hello.vt` 与 `notes.txt` 两个普通窗口；程序和字体都从真实文件系统读取。
当前为 US 键位输入，显示 UTF-8 与 BMP 中文字形，补充平面使用缺字框；无中文输入法和复杂排版。

| 操作 | 键位 |
|---|---|
| 移动、选择 | 方向键、Home/End，Shift 扩选 |
| 保存 | Ctrl+S |
| 打开 `/work` 内已有文件 | Ctrl+O，输入相对路径，Return；Esc 取消 |
| 复制、剪切、粘贴、全选 | Ctrl+C/X/V/A；剪贴板为本进程所有，≤64 KiB |
| 选择 `/work` 内构建清单 | Ctrl+M，输入相对路径，Return；Esc 取消 |
| 保存当前文档并构建已选清单（默认 `program.build`） | Ctrl+B |
| 取消本窗口构建 | Esc |
| 跳转至首条保留的源码诊断 | Ctrl+J；源码必须与该次快照内容一致 |
| 运行清单指定的当前已发布程序 | Ctrl+R |
| 桌面重新打开编辑器 | Ctrl+Alt+E，最多两个桌面启动实例 |
| 强制终止焦点窗口及其后代 | Ctrl+Alt+Esc，或右键标题栏关闭按钮 |

普通关闭遇到未保存修改会提示先保存；强制关闭会丢弃修改。打开其他文件也要求当前修改先保存。
当前清单显示在文件名下方。选择清单不切换文档；无效清单保持旧选择，构建进行中拒绝更换。
`compiler.build` 与 `kernel.build` 分别重建编译器与完整内核（包含 S0）。
Ctrl+R 运行的是磁盘上已发布版本，失败或取消构建后可能仍是上一次成功版本。内核 ELF 仅保存，
不能作为普通应用运行。应用退出状态显示在日志中。

文档上限 4 MiB，日志保留最后 1 MiB，丢弃旧内容会明确标记。若对应输入映射已经丢弃，则拒绝
诊断跳转并要求重建。构建与程序执行都是子进程，编辑器继续处理窗口事件；编辑器退出时内核
负责取消后代及回收句柄、页和在途请求。

首版使用固定 640×480 内容区、光标跟随滚动，不提供窗口缩放、鼠标拖选、跨进程剪贴板、
撤销重做或新建文件对话框。布局后逐行比较像素，只上传实际变化的行；交互性能仍以 K7 验收报告实测值为准。
